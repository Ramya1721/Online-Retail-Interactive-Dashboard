# Online Retail Sales Analysis Dashboard

## Project Overview
This project presents an interactive dashboard for analyzing an online retail dataset. It explores sales trends, customer behaviour, product performance, and country-wise revenue using Python and Plotly.

## Objectives
- Analyze overall retail sales performance.
- Identify top-performing products.
- Understand monthly revenue trends.
- Explore customer and transaction patterns.
- Visualize sales distribution across countries.

## Technologies Used
- Python
- Pandas
- NumPy
- Plotly
- Google Colab
- Jupyter Notebook

## Visualizations
1. Monthly Revenue Trend – Line Chart
2. Top 10 Products by Revenue – Bar Chart
3. Revenue Contribution by Country – Pie Chart
4. Unit Price Distribution – Histogram
5. Quantity vs Revenue – Scatter Plot
6. Sales by Day and Month – Heatmap

## Interactive Features
- Year and country filters in Google Colab.
- Interactive chart hover information.
- Zooming and panning.
- Dynamic dashboard updates based on selected filters.

## Dataset
Online Retail Dataset – UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/352/online+retail

## Project Files
- `Online_Retail_Dashboard.ipynb` – Complete Python notebook and interactive filters.
- `Online_Retail_Dashboard.html` – Exported interactive Plotly dashboard.

## How to Run
1. Download the notebook.
2. Open it using Google Colab.
3. Upload the Online Retail Excel dataset.
4. Run the notebook cells in order.
5. Use the year and country dropdown filters to explore the dashboard.
